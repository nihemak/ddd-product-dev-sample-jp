# イテレーション 2025-W23 バックログ

* **期間:** 2025-06-01 - 2025-06-07
* **ゴール:** フロントエンド開発環境の抜本的安定化を目的として、NxワークスペースでNext.js + Storybook + Playwright + Vitestの統合環境を新規構築し、既存機能を移植する
